# Род Барбул — генеалогическое досье

Сайт: https://kilevoy.github.io/barbul-family-history/

- `index.html` — основное досье: Рыбница 1796–1848, ветви Терентия, Ефрема, Трофима, Буграновых, источники и отметки «документально» / «гипотеза».
- `bugranov-sapozhnikov/index.html` — отдельное интерактивное древо казачьих ветвей Буграновых и Сапожниковых, связанное с основным древом через Надежду Сергеевну Бугранову.
- `marriage-audit/index.html` — архивно-аналитическая страница о поиске венчаний Тимофея Бугранова с Екатериной Рогожниковой и Антона Сапожникова с Евгенией Поликарповной.

Отдельная страница: https://kilevoy.github.io/barbul-family-history/bugranov-sapozhnikov/

Архивный аудит венчаний: https://kilevoy.github.io/barbul-family-history/marriage-audit/
