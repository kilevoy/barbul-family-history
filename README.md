# Летопись рода Барбул

Интерактивное генеалогическое древо и семейная хроника рода Барбул.

## Открыть сайт

После публикации GitHub Pages сайт доступен по адресу:

https://kilevoy.github.io/barbul-family-history/

## Содержание

- генеалогическое древо;
- хронология семейной истории;
- сведения об архивных делах и нерешённых вопросах исследования.

## Примечание об источниках

Часть сведений подтверждена семейными документами и архивными материалами, часть обозначена как гипотезы и требует дополнительной проверки. В публичной версии скрыты точные даты рождения и частные сведения о живых людях.
