# Род Барбул — семейная летопись

Версия 2 интерактивного семейного архива рода Барбул.

## Открыть сайт

https://kilevoy.github.io/barbul-family-history/

## Содержание

- общее генеалогическое древо;
- поиск по персонам;
- биографические карточки;
- хронология семейной истории;
- архивные находки и нерешённые вопросы исследования;
- разделение сведений по уровням достоверности.

## Версии

- `v1.0.0` — первая опубликованная версия;
- `v2.0.0` — обновлённые дизайн, структура и интерактивное древо.

## Примечание об источниках

Часть сведений подтверждена семейными документами и архивными материалами, часть обозначена как гипотезы и требует дополнительной проверки. В публичной версии не следует размещать чувствительные сведения о живых родственниках без их согласия.
